# Vigilância dos indicadores da APS · Dourados-MS

Site que transforma os relatórios do PEC e-SUS APS ("Acompanhamento de condições de saúde", exportados em CSV)
nas planilhas de monitoramento dos indicadores C2, C3, C4, C5, C6 e C7, com painel, prospecção e pendências por pessoa.

- Endereço: https://joaoinovaaps-maker.github.io/vigilancia-aps/
- Os relatórios são lidos no navegador do profissional. A planilha Excel é montada no próprio aparelho.
- O servidor (Google Apps Script) guarda só o registro de uso e, quando escolhido, cria a planilha no Google Planilhas.
- Regras: Notas Metodológicas C2 a C7 (SAPS/Ministério da Saúde). Modelo das planilhas de vigilância da UBS Ildefonso Pedroso.
