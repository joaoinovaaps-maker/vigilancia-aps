Seleção personalizada

Assinatura digital pelo gov.br

  1. Baixe o PDF. Recomenda-se gerar um arquivo por assinante: profissional (Prescrição + Laudo) e paciente/responsável (Termo + Autorização).
  2. Acesse assinador.iti.gov.br e entre com a conta gov.br (nível prata ou ouro).
  3. Envie o PDF, posicione a assinatura sobre a linha correspondente e confirme com o código enviado ao celular.
  4. Baixe o arquivo assinado. Se o mesmo documento precisar de mais de uma assinatura, o arquivo já assinado é enviado novamente ao assinador pela próxima pessoa.
  5. Para conferir: validar.iti.gov.br.

Se o paciente não tiver conta gov.br prata/ouro, imprima o Termo e a Autorização para assinatura manual.

Dados e privacidade

Os dados ficam apenas neste navegador (rascunho salvo automaticamente) e não são enviados a nenhum servidor. Após gerar os PDFs, use “Novo paciente” para apagar os dados — principalmente em computadores compartilhados.

Banco de dados anonimizado das solicitações de OPM

Cada solicitação gera um registro sem dados pessoais do paciente: não entram nome, CPF, RG, CNS, prontuário, data de nascimento, filiação, endereço, CEP, telefones, responsável, autorizado, nº da APAC nem textos livres de observação. São registrados: OPM solicitada (código, nome e quantidade), medidas e especificações da cadeira, perfil clínico (patologia, etiologia, CID-10), perfil demográfico agregado (sexo, idade, faixa etária, raça/cor, peso, altura, IMC), território (município, bairro, ESF), profissional solicitante e datas do fluxo.

Envio automático ao Google Planilhas (opcional)

Com a URL configurada, cada registro é enviado também para uma planilha online, consolidando as solicitações de todos os computadores da unidade.

Como configurar (uma única vez, ~5 minutos)
  1. Crie uma planilha no Google Planilhas (ex.: “Banco OPM – UBS”).
  2. Menu Extensões › Apps Script. Apague o conteúdo e cole o código abaixo.
  3. No início do código, em EMAIL_DESTINO, informe o e-mail institucional (vários: separe por vírgula). Salve.
  4. Selecione a função testarEmail e clique em Executar para autorizar o envio de e-mails. Não execute a função doPost pelo editor: ela só funciona quando recebe dados do formulário. Opcional: execute criarEnvioSemanal ou criarEnvioMensal para receber a planilha completa (XLSX) com resumo.
  5. Armazenamento no Drive: execute organizarPlanilhaNaPasta (move a planilha para a pasta “Banco OPM - dados anonimizados”) e criarCopiaDiariaNoDrive (salva uma cópia CSV diária na mesma pasta).
  6. Implantar › Nova implantação › tipo App da Web. Executar como: Eu. Quem pode acessar: Qualquer pessoa. Autorize.
  7. Copie a URL terminada em /exec, cole no campo acima e clique em Salvar e depois em Testar. A aba “Registros OPM” será criada na planilha.

Registros com o mesmo ID são atualizados, sem duplicar linhas. A URL deve ser compartilhada apenas com a equipe.
