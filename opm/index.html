Seleção personalizada

Assinatura digital pelo gov.br

  1. Baixe o PDF. Recomenda-se gerar um arquivo por assinante: profissional (Prescrição + Laudo) e paciente/responsável (Termo + Autorização).
  2. Acesse assinador.iti.gov.br e entre com a conta gov.br (nível prata ou ouro).
  3. Envie o PDF, posicione a assinatura sobre a linha correspondente e confirme com o código enviado ao celular.
  4. Baixe o arquivo assinado. Se o mesmo documento precisar de mais de uma assinatura, o arquivo já assinado é enviado novamente ao assinador pela próxima pessoa.
  5. Para conferir: validar.iti.gov.br.

Se o paciente não tiver conta gov.br prata/ouro, imprima o Termo e a Autorização para assinatura manual.

Dados e privacidade

Os dados do paciente ficam apenas neste navegador (rascunho salvo automaticamente) e não são enviados a nenhum servidor; quando marcado, só é registrada a solicitação sem dados pessoais (OPM, medidas e informações clínicas gerais). Após gerar os PDFs, use “Novo paciente” para apagar os dados — principalmente em computadores compartilhados.
